# CLOTH — taparabos (falda abierta por delante)
# Formato: @CLOTH nombre ancla wTop wBot height offY offX offZ rot colorRGBA physics
#
# Tabla de ángulos (personaje mirando +Z):
#   rot=  0  → panel mira hacia ADELANTE  (+Z)  right apunta a la derecha
#   rot= 90  → panel mira hacia la DERECHA (+X)  (tu derecha)
#   rot=180  → panel mira hacia ATRÁS     (-Z)
#   rot=270  → panel mira hacia la IZQUIERDA (-X)
#   rot= 45  → diagonal adelante-derecha
#   rot=135  → diagonal atrás-derecha
#   rot=225  → diagonal atrás-izquierda
#   rot=315  → diagonal adelante-izquierda
#
#  offsetZ desplaza el panel en la dirección outward (fwd) → siempre hacia afuera del cuerpo
#  El constraint cilíndrico evita que cualquier vértice se meta dentro del cuerpo
#  desde cualquier dirección, no solo la frontal.
#
#      nombre     ancla wTop	wBot	height	offY	offX	offZ	rot	color	  physics
